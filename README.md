# 🐦 Flappy Bird Clone

A clone of the classic Flappy Bird game, built in Unity. This game is designed to be simple, addictive, and fun, just like the original.

---

## 🎮 Features
- Simple one-tap controls to make the bird fly
- Randomly generated pipes that the bird must navigate
- Score tracking to see how long you can last
- Simple UI showing the score and game over screen

---

## 🕹️ Controls
- **Flap**: Tap anywhere on the screen (Android) or **Left Click** (PC) to make the bird fly.

---

## 📱 Platform
- Developed with **Unity 2D**
- Available for **Android** and **PC**

---

## 🚀 How to Run

✅ This game is complete and ready to play.

📱 **APK for Android**: Download and install the APK on your Android device.

💻 If you’re a developer and want to explore the code:
1. Open the project in **Unity 2021.3 LTS** or newer
2. Open the main scene from the `Scenes` folder
3. Press **Play** to preview in the editor
